# LLMs

The docs are also published as Markdown for LLMs and agents, following [llms.txt](https://llmstxt.org).

## Files

| File | Content |
| --- | --- |
| <n-a href="/llms.txt" target="_blank">llms.txt</n-a> | An index of every page, grouped as in this site's menu, each with a one-line description |
| <n-a href="/llms-full.txt" target="_blank">llms-full.txt</n-a> | Every page in one file |
| <n-a href="/zh-CN/llms.txt" target="_blank">zh-CN/llms.txt</n-a>, <n-a href="/zh-CN/llms-full.txt" target="_blank">zh-CN/llms-full.txt</n-a> | The same in Chinese |

## A page as Markdown

Add `.md` to the address of any docs or component page, for example <n-a href="/en-US/components/button.md" target="_blank">/en-US/components/button.md</n-a>. Component pages include the API and the full source of every demo.

The button next to each page title copies the page as Markdown, copies its Markdown link, or opens it.

## With an agent

Give the agent the address of `llms.txt` (`https://www.naiveui.com/llms.txt`) and let it read the pages it needs. `llms-full.txt` holds the source of every demo, so it is large: use it with tools that index a whole file.
