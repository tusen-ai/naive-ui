# LLMs

文档也提供给大模型和 Agent 使用的 Markdown 版本，遵循 [llms.txt](https://llmstxt.org) 规范。

## 文件

| 文件 | 内容 |
| --- | --- |
| <n-a href="/zh-CN/llms.txt" target="_blank">zh-CN/llms.txt</n-a> | 所有页面的索引，按本站菜单分组，每页附一句说明 |
| <n-a href="/zh-CN/llms-full.txt" target="_blank">zh-CN/llms-full.txt</n-a> | 所有页面合在一个文件里 |
| <n-a href="/llms.txt" target="_blank">llms.txt</n-a>、<n-a href="/llms-full.txt" target="_blank">llms-full.txt</n-a> | 英文版 |

## 单个页面的 Markdown

在任意文档页或组件页的地址后面加上 `.md`，例如 <n-a href="/zh-CN/components/button.md" target="_blank">/zh-CN/components/button.md</n-a>。组件页包含 API 和每个示例的完整源码。

每个页面标题旁边的按钮可以把页面复制为 Markdown、复制 Markdown 链接，或者直接打开。

## 给 Agent 用

把 `llms.txt` 的地址（`https://www.naiveui.com/zh-CN/llms.txt`）交给 Agent，让它按需读取需要的页面。`llms-full.txt` 包含所有示例的源码，体积较大，适合能索引整个文件的工具。
